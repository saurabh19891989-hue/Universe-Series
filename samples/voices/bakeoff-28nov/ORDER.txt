== casting-clips/  (not in the reel; ~10 s each, -20 LUFS)
  kokoro-<CHAR>.mp3    the reference fed to "Chatterbox, Kokoro voice": our own E01 Kokoro stems joined (lines not in the test).
  designed-<CHAR>.mp3  the reference fed to "Chatterbox, designed voice": one clip per character made by Qwen3-TTS VoiceDesign
                       from a written description (no real person). Listen to these first to judge the designed voices
                       themselves (accent of Mira: Bengali-English intended; Temi: Nigerian-English intended).

How each engine was directed (exact text and tags per take are in the timings-*.json files under numbers/):
  Supertonic         preset voices M1/M3/F5/F2, inline <laugh> <breath> <sigh>, speed 0.75-1.5, caps for the shout.
  Qwen voice design  every line = character description + the director's note in words (no tags); voice re-invented each line.
  Chatterbox (both)  same reference clip for every line of a character + inline tags ([fear] [surprised] [gasp] [sarcastic]
                     [angry] [dramatic] [whispering] [sigh] [chuckle] [laugh] [happy]).
  Orpheus            stock US voices zac/dan/leah/jess, inline <gasp> <sigh> <chuckle> <laugh>, caps and "!!". Line 1 has
                     only one Orpheus take (the second was stopped to save time).
